# Бот слежения за нулевыми транзакциями ETH

Следит за кошельками Ethereum и присылает админу в Telegram сообщение, когда на кошелёк
приходит внутренняя транзакция на 0 ETH (на Etherscan они видны только с «Advanced mode»).
По кнопке показывает адреса отправителей и сколько на них лежит.

Данные берутся из Blockscout — бесплатно, без ключа, нулевые транзакции он видит.
Задержка — обычно 1–5 минут после попадания транзакции в блок.

## Запуск на bothost.ru (через GitHub)

1. Загрузите все файлы этой папки в корень репозитория на GitHub (Add file → Upload files).
2. На bothost.ru создайте бота: язык Python, токен от @BotFather, ссылка на репозиторий.
   Главный файл — `bot.py` (определяется автоматически).
3. В «Переменные окружения» впишите:
   - `ADMIN_IDS` — ваш Telegram ID;
   - `WALLETS` — полный адрес кошелька (несколько — через запятую).
   `BOT_TOKEN` bothost подставляет сам.
4. Запустите и напишите боту `/start` — появится меню с кнопками.

На бесплатном тарифе данные стираются при перезапуске, поэтому кошельки лучше держать
в `WALLETS`. Транзакции, пришедшие, пока бот был выключен, он не пришлёт.

## Кнопки и команды

| Кнопка / команда | Что делает |
|---|---|
| «📜 Контракт» под уведомлением | контракт, приславший эту транзакцию, если на нём есть ETH |
| «👤 Создатель» под уведомлением | кошелёк, создавший этот контракт, если на нём больше $10 в ETH |
| «📜 Контракты» в меню, `/contracts` | все контракты, присылавшие 0 ETH (вся история), только с ETH на балансе |
| «👤 Создатели контрактов» в меню, `/creators` | кто создал эти контракты, только с балансом больше $10 (`MIN_CREATOR_USD`) |
| «🔎 Тест», `/test [адрес]` | сколько нулевых транзакций видят источники по кошельку |
| «📋 Кошельки», `/list` | список кошельков |
| `/add <адрес> [метка]` | начать следить за кошельком |
| `/remove <адрес>` | перестать следить |
| `/check` | проверить прямо сейчас |
| `/status` | источник, интервал, последняя проверка и ошибка |

Баланс показывается в ETH и долларах, плюс до 5 крупнейших токенов (USDT, USDC и т.п.)
с известной ценой. Токены без цены и помеченные как скам не показываются.

## Если Blockscout недоступен

Бот сам переключается на запасной источник — бесплатные публичные узлы Ethereum
(eth.drpc.org, eth.merkle.io) — и пишет об этом. Раз в 10 минут он проверяет, не ожил ли
Blockscout, и возвращается на него. В запасном режиме:
- слежение и уведомления работают как обычно;
- балансы показываются только в ETH (без токенов), цена ETH — с Coinbase/CoinGecko/Kraken;
- создателя контракта бот ищет сам — это дольше (до минуты на контракт), но результат
  запоминается.

Список запасных узлов можно поменять переменной `FALLBACK_RPCS` (через запятую).

## Важно

Нулевые транзакции от незнакомых контрактов часто означают **address poisoning**:
мошенники подсовывают в историю адреса, похожие на ваши. Никогда не копируйте
адрес получателя из истории транзакций.
